# FFBE sprites — labelled index

A labelled manifest for [arandooku/ffbe-sprites](https://github.com/arandooku/ffbe-sprites): the images
stay there; this repo only holds `index.json`, whose `base` points at them.

- Units labelled from the [aEnigmatic/ffbe](https://github.com/aEnigmatic/ffbe) GL datamine (MIT):
  name, job, origin series and rarity, e.g. "Rain (Knight) ★6". JP-only units keep the dump's names.
- Categories: each origin series, then Faces, Battle sprite sheets, Animations (GIF), Monsters.
- 57,719 entries. Rows: `[path, name, subcategory, category, file]`.
